# telecom_data_projects
Casos de estudio de analítica y arquitectura de datos para el sector Telecomunicaciones. Implementaciones de flujos ETL, modelado de datos corporativo y dashboards de alto impacto para la toma de decisiones en servicios de entretenimiento. Enfocado en la gestión de KPIs de negocio, trazabilidad operativa y gobernanza de datos
